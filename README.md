# Local-Market-Simulator-A-Game-Theory-Application
Run the .py file
Navigate through the menu
Choose "Έναρξη προσομοίωσης" to start the simulation or "Ορισμός Παραμέτρων" to set the Parameters
After "Έναρξη προσομοίωσης" you can see the simulation graph, and you can export the graph, the text details or return to the main menu using the buttons below
After "Ορισμός Παραμέτρων" you can choose the number of rounds you want the sim to run for, the round the Supermaket gets involved and even the amount of players that are part-taking in the game. Also you can edit the payoff matrices according to your preferencies and scientific curiosity.
You can also go back to the main menu

That's all preatty much.


ATTENTION: if you run the .py file, it must be in the same folder as the shops.png.
